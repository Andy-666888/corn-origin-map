# 玉米产地分布地图

嘉吉工厂及竞争厂家交互式分布图。

## 功能

- 🌟 **嘉吉工厂** (红色五角星) / **竞争厂家** (蓝色三角) / **可用厂家** (绿色圆) / **关注厂家** (蓝色圆)
- 🔍 左侧嘉吉工厂模糊搜索，联动右侧明细面板
- 📏 批量测距工具
- ⭕ 画圈工具（150/200/300/500km 四档）
- 📊 Excel 一键导入更新数据
- 🖱️ 各类别滑块开关控制显示/隐藏

## 在线访问

[https://andy-666888.github.io/corn-origin-map/](https://andy-666888.github.io/corn-origin-map/)

## 数据格式

Excel 模板包含 4 个 Sheet：
| Sheet | 说明 | 关键字段 |
|-------|------|----------|
| 嘉吉工厂 | 27家嘉吉工厂 | 名称/省/市/区县/经度/纬度 |
| 竞争厂家 | 关联竞争厂家 | 名称/省/市/区县/经度/纬度/关联嘉吉工厂 |
| 可用 | 可用产地 | 名称/省/市/区县/经度/纬度 |
| 关注 | 关注产地 | 名称/省/市/区县/经度/纬度 |

坐标系：GCJ-02（高德坐标系）
